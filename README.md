Project Name & Type: VisionMeet – A real-time video call and chat platform.

Tech Stack: Built using Node.js, Express.js, WebRTC, and Stream API.

Core Features: Real-time video conferencing and chat, supporting peer-to-peer calls with up to 5 users per session.

UI/UX: Intuitive interface for seamless video calling and messaging experience.

Performance/Impact: Low latency (<200ms) and scalable backend architecture to handle concurrent users efficiently.

Development Methodology: Deployed on cloud hosting with continuous monitoring for reliability and performance.
